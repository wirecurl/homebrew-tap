# wirecurl Homebrew tap

Homebrew packages from [wirecurl](https://github.com/wirecurl).

```sh
brew install --cask wirecurl/tap/ferge
```

| Package | What |
|---|---|
| [ferge](https://github.com/wirecurl/ferge) | A fast, keyboard-first file transfer client (SFTP) for macOS and Linux |

The casks are updated by the release workflows of their projects.
